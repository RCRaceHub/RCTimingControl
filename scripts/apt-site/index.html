RC Timing Control apt repository

For Ubuntu, Debian and other Debian-based Linux on 64-bit Intel or AMD (amd64) and 64-bit ARM such as a Raspberry Pi 4 or 5 (arm64). Run these on the venue laptop:

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/rctc-archive-keyring.gpg https://rcracehub.github.io/RCTimingControl/apt/rctc-archive-keyring.gpg
sudo curl -fsSL -o /etc/apt/sources.list.d/rctimingcontrol.sources https://rcracehub.github.io/RCTimingControl/apt/rctimingcontrol.sources
sudo apt update
sudo apt install rctimingcontrol

Then open http://localhost:8080 to set up the club. Later releases arrive with sudo apt update && sudo apt upgrade; the service restarts and keeps its data.

Packages are signed. The key is rctc-archive-keyring.asc.
