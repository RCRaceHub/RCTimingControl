# Endpoints that change data (POST, PUT, PATCH, DELETE) and are not marked @Audited, each with why.
# AuditCoverageIT fails if a mutating endpoint is in neither place, and also if an entry here is stale (the
# endpoint is gone or is now @Audited), so this list only shrinks. Format: METHOD /pattern | reason
#   GAP      nothing records who did it. Fixed under #139.
#   READ-ONLY  a POST that changes nothing.
#   EXEMPT   changes only bookkeeping, no data an official relies on; the reason says why.
POST /api/v1/admin/competitors/spoken-name/preview | READ-ONLY: plays the text, stores nothing
POST /api/v1/admin/events/{eventId}/entry-feed/fetch | EXEMPT: downloads the file and holds it for an official to confirm, changing no entries; the import it leads to is audited
POST /api/v1/admin/events/{eventId}/entry-feed/preview | READ-ONLY: previews the held file, applies nothing
POST /api/v1/race-control/race/{raceId}/skip-to | READ-ONLY: checks the run order, stores nothing
POST /api/v1/race-control/race/{raceId}/featured-driver | READ-ONLY: sends a one-off message to the stream overlay, stores nothing
POST /api/v1/setup/decoder-config/test | READ-ONLY: tries a decoder address, saves nothing
